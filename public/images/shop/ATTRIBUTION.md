# Hardware reference photographs

These photographs show representative hardware, not the illustrative products offered in the demo catalog. They were selected from Hallmark's Wikimedia Commons photo library and downloaded locally at 1920px. The source image licenses apply to the photos; they do not license the application code.

- `canoscan-5600f-main-pcb-top-view-1920.jpg`: [CanoScan 5600F main PCB top view](https://commons.wikimedia.org/wiki/File:CanoScan_5600F_main_PCB_top_view.jpg), Mister rf, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Resized from the original; displayed with CSS cropping.
- `2023-wkretak-elektryczny-xiaomi-1920.jpg`: [2023 Wkrętak elektryczny Xiaomi](https://commons.wikimedia.org/wiki/File:2023_Wkr%C4%99tak_elektryczny_Xiaomi.jpg), Jacek Halicki, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Resized from the original; displayed with CSS cropping.

The LeRobot reference photograph used elsewhere retains its existing attribution and license in `public/images/ATTRIBUTION.md` and `public/images/LEROBOT-LICENSE.txt`.
